# Alpha EMA — Confirmed Structure Engine

Responsive HTML/CSS/JavaScript documentation website based on the supplied Pine Script V19.1.

## Files
- `index.html` — page structure and strategy documentation
- `style.css` — responsive dark trading-terminal design
- `script.js` — interactive engine module tabs and mobile navigation

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Put these four files in the root of a GitHub repository.
2. In Vercel, select **Add New → Project** and import the repository.
3. Framework Preset: **Other**.
4. Build Command: leave blank; Output Directory: `.` (or leave the default for a static site).
5. Click **Deploy**.

The chart graphic is illustrative, not live data. This website does not execute trades or connect to TradingView.
